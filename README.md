# Daily Calorie Needs Calculator

A simple, responsive calorie-estimation tool. It uses age, sex, height, weight, and typical activity level to estimate basal metabolic rate (BMR), maintenance calories, and general weight-change targets.

## Pages

- [`index.html`](./index.html) — landing page
- [`daily-calorie-needs-calculator.html`](./daily-calorie-needs-calculator.html) — calculator

## Use locally

Open `index.html` in a web browser, then select **Open Calculator**. No server, build step, or dependencies are required.

## Calculation

The calculator uses the Mifflin–St Jeor equation to estimate BMR, then applies an activity factor to estimate maintenance calories. The activity options range from sedentary to extra active.

## Disclaimer

Results are estimates for general guidance, not medical advice. Individual energy needs vary. Speak with a GP, nurse, or dietitian before making significant changes to your diet or weight.
